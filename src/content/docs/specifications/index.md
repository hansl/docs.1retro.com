These are the formats and protocols behind 1Retro. They are written to be implemented by anyone, not just by 1Retro
itself.

Types that more than one specification needs live in [Common Types](/specifications/common-types/), so a name means the
same thing everywhere it appears.

The [Glossary](/specifications/glossary/) does the same for the words: what a bundle is against what a save is, and
which of a producer, a consumer and a writer a given rule is talking to.
