## What it tags

A two-element array: a header map, then an array of parts. The tag identifies the document and pins its major version,
so a later incompatible format takes a different tag and an old decoder rejects it on the tag alone.

## Magic number

The tag's five-byte head is the file magic. A bundle begins:

```text
0xDA 0x31 0x53 0x41 0x56
```

`0xDA` is the CBOR head for a four-byte tag; the remaining four bytes are `0x31534156`, which reads `1SAV` in ASCII from
byte 1. A bundle never carries the self-describe tag 55799, so the magic sits at the start of the file.
